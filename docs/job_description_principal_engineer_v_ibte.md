## Job Summary

The Standard is seeking a **Principal Software Engineer V** with deep full-stack engineering and architecture expertise to support the IBTE strategic solution. In this role, the engineer will collaborate with Product Owners, Product Analysts, Scrum Masters, Front-End Engineers, Software Developers in Test, Data Engineers, DevOps / Site Reliability Engineers, and Architects to design and deliver scalable, secure, and reliable enterprise-grade applications.

This role is expected to own end-to-end technical architecture, define and govern architectural standards, lead design decisions and trade-off discussions, and ensure implementation aligns with enterprise architecture principles. The ideal candidate will bring deep hands-on expertise in Java/Spring Boot, Kafka and Confluent Platform, Azure-native engineering, Kong/Kong Konnect, AKS, Azure networking, CI/CD, Terraform, Docker/Kubernetes, database integration, and automation/performance testing practices.

---

## Key Requirements & Responsibilities

### Architecture Ownership

- Own end-to-end solution architecture across API services, event-driven components, cloud infrastructure, integration layers, data flows, security, observability, and operational readiness.
- Define, document, and govern architecture patterns, design guardrails, integration standards, and reusable engineering practices to ensure consistency across teams.
- Lead architecture reviews, evaluate technical options, make informed trade-off decisions, and ensure implementation choices align with enterprise architecture, security, scalability, and long-term maintainability goals.

### API Engineering and Integration

- Deep hands-on experience designing and building enterprise-grade REST APIs using Java and Spring Boot.
- Strong understanding of API design patterns, OpenAPI/Swagger specifications, performance optimization, resiliency, and production-grade service development.
- Ability to design secure, scalable integration patterns across frontend, backend, cloud services, and event-driven components.
- Ability to understand frontend integration patterns and guide teams on React-based frontend integration with backend systems and APIs.

### Kafka, Confluent Platform, and Event-Driven Architecture

- Strong experience with Apache Kafka and event-driven publish-subscribe patterns.
- Hands-on working knowledge of Confluent Platform components, including Kafka brokers/clusters, Schema Registry, Kafka Connect, connector development, and Apache Flink, including statements and UDFs.

### Azure Cloud, Networking, and DevOps

- Strong experience designing and implementing solutions on Microsoft Azure.
- Working knowledge of AKS, Azure networking, Application Gateway, Azure Firewall, Load Balancers, Key Vault, NSG, NAT, Private Link/Endpoint, VNET/subnet connectivity, Private DNS zones, and related Azure-native services.
- Strong experience with Azure DevOps, GitHub, Maven, Terraform, Docker, Kubernetes/AKS, and CI/CD pipeline implementation.
- Ability to define and drive engineering best practices across build, deployment, observability, reliability, and production support.

### Testing, Quality, and Reliability

- Experience with automation testing strategy, API testing, performance testing, and tools such as Selenium, Postman, Curl, JMeter, SOAPUI, Gatling, or similar.
- Ability to guide testability, quality gates, and non-functional validation for performance, scalability, reliability, and operational readiness.

### Data and Database Integration

- Strong experience integrating with SQL and NoSQL databases.
- Ability to write and review simple to complex queries and guide teams on data access patterns, performance, and reliability.

### Leadership and Collaboration

- Ability to operate independently, take initiative, and drive work with minimal direction.
- Strong communication skills with the ability to interact directly with business stakeholders, Product Owners, Architects, and engineering teams.
- Ability to translate business requirements into scalable technical solutions and provide technical leadership across multiple engineers.
- Ability to mentor API engineers, DevOps engineers, and automation testers while ensuring alignment to architecture and delivery goals.
