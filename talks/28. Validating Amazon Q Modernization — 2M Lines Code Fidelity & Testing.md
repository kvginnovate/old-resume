**Target:** Principal Software Engineer V — The Standard (IBTE)
**Duration:** 90-100 seconds

---

## Question

**Interviewer:** "On your resume, you mention using Amazon Q for modernizing 2 million lines of legacy code into Spring Boot 3 microservices with 70% faster delivery. What did Amazon Q actually output? Was the code production-ready, and how did you validate behavioral fidelity?"

---

## Answer

To be clear: Amazon Q did not generate 2 million lines of production-ready code autonomously with the click of a button. The 2 million lines represents the total legacy monolithic codebase (Ruby on Rails + legacy Java services) that we transformed into modern Spring Boot 3 microservices.

Our transformation strategy used Amazon Q as an **acceleration engine within a rigorous human-in-the-loop harness**:

**1. What Amazon Q Output:**
Amazon Q excels at boilerplate translation, schema mapping, and converting legacy web controllers or data mappers into standard Spring Boot 3 annotations and DTOs. However, initial AI outputs contained flaws—such as unoptimized database access, legacy exception handling patterns, or incomplete security filters.

**2. The Validation Harness (How We Ensured 100% Fidelity):**
- **Automated Specification Harness:** Before touching code, we used Kiro and EARS (Easy Approach to Requirements Syntax) to extract exact functional specifications and API contracts from legacy endpoints.
- **Parallel-Run Differential Testing:** We deployed the new Spring Boot 3 services in parallel with legacy services in staging. Using shadow traffic (traffic mirroring), we executed identical production-like requests to both systems and automated diff checks on the API responses.
- **Automated Test Generation:** We built an automated pipeline where unit and integration test suites (10,000+ tests) were generated and validated against legacy edge cases, bringing code coverage above 85%.

Amazon Q reduced manual refactoring effort by 70%, allowing our senior engineers to focus on architectural boundaries, database isolation, and security rather than typing boilerplate.
